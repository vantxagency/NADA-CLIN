# Nada Skin — GitHub Pages

Static one-page demo. Files: index.html, style.css, and ordered script files. No framework, build command, or backend required.

## Publish

1. Create a GitHub repository.
2. Upload the files in this folder to the root of the repository (not the folder itself).
3. Open Settings → Pages → Build and deployment. Select Deploy from a branch.
4. Choose the main branch and / (root), then save. GitHub Pages will display its URL after deployment.

## Notes

- Demo only: checkout, electronic payment, and the contact number are not connected. Do not use real payment data.
- Product images are externally hosted and may fail to load; pricing is a historical reference, not live stock or pricing.
- The Cairo font loads from Google Fonts when available; local fallback fonts are provided.
- English translation is incomplete. Verify product details, imagery rights and checkout before real use.
- To test locally, open index.html in a browser, or run `python -m http.server` in this folder.
